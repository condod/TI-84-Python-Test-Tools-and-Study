# Statistics, Probability & Discrete Math Bundle — TI-84 Plus CE Python

5 standalone TI-84 Plus CE **Python Edition** programs for an introductory statistics
course and the discrete-math/counting topics that sit alongside it.

## What's Included

| File | What it does |
|---|---|
| `descriptive_stats.py` | Mean, median, mode, min/max/range, and both sample and population variance and standard deviation from a list of up to 90 values. |
| `confidence_interval_hypothesis_test.py` | One-sample confidence interval for a population mean and a one-sample hypothesis test, using a z critical value (σ known) or a t critical value (s, df = n−1) from a built-in table. Prints the interval, or the test statistic, critical value, and a reject / fail-to-reject conclusion. |
| `combinatorics_probability.py` | Permutations (nPr), combinations (nCr), and binomial probability. |
| `chi_square_genetics.py` | Chi-square goodness-of-fit test against a preset ratio (3:1, 9:3:3:1, 1:1, 1:2:1) or any custom ratio you type, with a per-category table of observed, expected and each contribution to χ², degrees of freedom, and built-in critical values at the 0.05 and 0.01 levels. Warns when an expected count drops below 5. |
| `discrete_math_toolkit.py` | Number base converter (binary, octal, decimal, hex) and a boolean truth-table generator for a typed expression of up to three variables using `and` / `or` / `not` / `^`. |

A note on `chi_square_genetics.py`: its presets are named for Mendelian crosses because
that is where students meet the test first, but the custom-ratio option makes it a
general goodness-of-fit test for any categorical data. It also ships in the Biology &
Lab Science bundle — if you buy both, it is the same file.

**Course fit:** Intro Statistics, Probability, Discrete Math, and the quantitative-methods
component of most social-science and lab courses.
