# Algebra, Precalculus & Trigonometry Bundle — TI-84 Plus CE Python

11 standalone TI-84 Plus CE **Python Edition** programs covering the arc from College
Algebra through Precalculus and Trigonometry — the sequence most students take before
calculus, plus the geometry and linear-systems tools those courses keep reaching for.

## What's Included

| File | What it does |
|---|---|
| `quadratic_solver.py` | Quadratic equation solver: discriminant, its classification, and either two real roots, one repeated root, or a complex conjugate pair written as `a ± bi`. |
| `quadratic_vertex_analyzer.py` | Builds a quadratic from its vertex plus one other point, then reports vertex form, standard form, domain/range, axis of symmetry, min/max, intercepts, and increasing/decreasing behavior. |
| `complex_number_calculator.py` | Complex arithmetic (add, subtract, multiply, divide), magnitude and argument, and rectangular ↔ polar conversion — all computed manually on real/imaginary pairs, since the calculator has no `cmath`. |
| `linear_system_solver.py` | 2×2 or 3×3 linear system solver by Gaussian elimination with partial pivoting; says so when a system is inconsistent or dependent. |
| `matrix_toolkit.py` | Matrix add, multiply, determinant, and inverse for 2×2 and 3×3 matrices you enter, with a friendly message for singular matrices. |
| `polynomial_analyzer.py` | Polynomial analysis (real zeros by bounded bisection, end behavior, intercepts, turning-point count) and rational-function analysis (vertical/horizontal/oblique asymptotes, holes, intercepts). |
| `sequences_series.py` | Arithmetic and geometric sequences and series: nth term, partial sums, common difference/ratio recovered from two terms, infinite geometric sums, and term listings. |
| `log_exp_solver.py` | Logarithm and exponential toolkit: change of base, solving `b^x = c` and `log_b(x) = c`, the log rules worked with your own numbers, and growth/decay with half-life and doubling time. |
| `oblique_triangle_solver.py` | Non-right-triangle solver using the Law of Sines and Law of Cosines: SSS, SAS, ASA/AAS, and the ambiguous SSA case (reporting 0, 1, or 2 valid solutions). |
| `unit_circle_reference.py` | Unit-circle reference and trig evaluator: all six functions at an angle with exact values named where they exist, reference angle, quadrant and sign pattern, degree/radian conversion, inverse trig, and identity checks. |
| `shape_geometry_solver.py` | Area and perimeter for circles, rectangles and triangles (Heron's formula, with a triangle-inequality check), plus volume and surface area for spheres, cylinders, cones and rectangular prisms. |

**Course fit:** College Algebra, Algebra II, Precalculus, Trigonometry, Geometry, and the
linear-systems and matrix portions of an intro Linear Algebra course.

## Install these a course at a time, not all eleven

All 11 programs come to about **58 KB** of Python AppVars, and a TI-84 Plus CE Python holds
roughly **50 KB**. So the full set does not fit on the calculator at once — and it is not
meant to. This bundle deliberately spans College Algebra through Trigonometry, which is two
or three different semesters.

Install the handful you need for the course you are actually taking, and archive or delete
them when it ends. Keep this ZIP — it is your backup, and you will want it after any
Press-to-Test or memory reset (see below).
