## Shared Copy Notes (apply to all listings)

- **No blanket legality claims.** Do not use phrases like "AP-Exam-Legal" as a guarantee.
  Use language such as: *"Calculator program policies vary by exam and instructor — please
  check your specific exam's calculator/program rules before bringing any stored program
  into a real test."*
- **Format transparency.** Every listing should note: *"Delivered as plain-text `.py`
  source files. Included install guide walks you through transferring them to your
  TI-84 Plus CE Python Edition using TI Connect™ CE, which converts them into the
  calculator's native Python program format automatically."*
- **Compatibility line** (recommended on every listing): *"Requires a TI-84 Plus CE
  **Python Edition** calculator (or TI-84 Plus CE with the Python App installed) and a
  computer running TI Connect™ CE for the easiest transfer. Not compatible with older
  monochrome TI-83/TI-84 models or TI-Nspire."*
