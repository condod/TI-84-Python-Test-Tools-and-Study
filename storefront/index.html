Installing takes about five minutes

You need a TI-84 Plus CE Python Edition (or a TI-84 Plus CE with the Python App installed), a USB cable, and TI's free TI Connect™ CE software. Buying a calculator for this? Check the compatibility FAQ first — the plain TI-84 Plus CE now sold by TI does not include Python. On a TI-84 Evo the process is different — see the Evo answer in the FAQ.

  1. 1

    Download and unzip

    Every bundle ships each program twice: a ready-to-install .8xv Python AppVar and the matching plain-text .py source, plus a README.

  2. 2

    Drag the .8xv files across

    Connect the calculator by USB, open TI Connect™ CE (free from Texas Instruments) and drag the .8xv files onto the device. No copy-pasting code, no retyping.

  3. 3

    Open the Python App and run

    The programs appear in the Python App's list on the calculator. Pick one and run it. That's the whole process.

The .py source is there so you can read the algorithm, change a tolerance or add your own formula — open it in the TI Connect CE Program Editor, or type it straight into the calculator's own Python editor if you don't have a cable to hand. Keep an eye on the roughly 50 KB / 100-program storage limit and archive what you're not using.

On a TI-84 Evo, steps 2 and 3 are different. TI Connect™ CE does not connect to an Evo, and the Evo can't read .8xv files — it uses a newer AppVar format. You send the included .py files instead, through TI's web app at connectevo.ti.com (Chrome, a USB-C cable and an internet connection), which converts each file as it sends. Every bundle already contains those .py files, so nothing extra to buy. Read the full Evo answer in the FAQ — including what is and isn't confirmed on that hardware.

Questions people actually ask

Which calculators does this work on?

The TI-84 Plus CE Python Edition, and a TI-84 Plus CE that has TI's Python App installed. Those are the two the programs are built and tested for.

The TI-84 Evo, TI's 2026 successor model, has Python built into every unit and is expected to run these too — but you must use the included .py files rather than the .8xv files, and they have not yet been tested on Evo hardware. See the Evo answer below.

It does not work on the older monochrome TI-83 Plus or TI-84 Plus, the TI-84 Plus Silver Edition, the TI-Nspire family, or any Casio or HP calculator. Those either have no Python environment or a different one. If you're unsure, check the label on your calculator's faceplate for "Python" or look for a Python app in the Apps list before buying.

I'm about to buy a TI-84 — what exactly should I get?

Check for the word "Python" before you pay. This matters more than it used to. Texas Instruments discontinued the TI-84 Plus CE Python on 27 April 2026, and the plain TI-84 Plus CE that TI currently sells does not include Python. TI has named the TI-84 Evo as the successor model.

So a calculator bought new today under the "TI-84 Plus CE" name may be a unit that cannot run these programs at all. Before you buy hardware: look for "Python" printed on the faceplate or bezel, or switch the calculator on and confirm a Python app appears in the Apps list. If you already own a TI-84 Plus CE without Python, check TI's site for the Python App for your model and OS version.

Buying an Evo instead? That works differently — every Evo has Python built in, but you install from the .py files rather than the .8xv files, and Evo compatibility has not been verified on hardware yet. The next answer covers it in full.

Second-hand TI-84 Plus CE Python units remain widely available, and the free starter pack is the cheapest way to confirm your specific calculator works before you buy anything.

I have a TI-84 Evo — will these work?

Very probably, and you install them a different way — but we haven't proved it on hardware yet, so we won't claim it as tested. Here is exactly what is known.

Good news first. The TI-84 Evo, which replaced the CE Python in April 2026, ships with Python on every unit — there's no "Python Edition" to hunt for any more. TI documents the same core modules these programs use (math, random, time), and every program here is plain Python with no dependency on the CE's screen size or key layout, so there is nothing obvious for the Evo to break.

The catch: use the .py files, not the .8xv files. The Evo uses a new AppVar format (.8xv2), so the ready-made .8xv files in every bundle will not transfer to it — and TI Connect™ CE won't even connect to an Evo. Instead, open TI's web app at connectevo.ti.com in Chrome, plug the calculator in with a USB-C cable, and send the .py files from the bundle's py/ folder. TI Connect™ Evo converts each one to the Evo's own format as it sends. You need an internet connection, since the tool is a web app, and Chrome specifically, because it relies on WebUSB.

What we won't say. Nobody here has run these 156 programs on an Evo. The reasoning above is an informed expectation from reading the code and TI's documentation, not a test result, and we won't advertise Evo support until it's been tested on a real unit. If you're buying specifically for an Evo, take the free starter pack first and confirm on your own calculator before you pay for anything. If something doesn't work, email me.

One more thing: any keystroke-by-keystroke instruction or screenshot you find for these programs was made on a TI-84 Plus CE. The Evo's keypad was rearranged, so the keys may not be where CE instructions say.

How do I actually get the programs onto the calculator?

With TI Connect™ CE, Texas Instruments' free desktop software. Connect the calculator over USB, open the Program Editor, create a new Python program, paste in the contents of a .py file and send it to the device. Then run it from the calculator's Python App. A step-by-step guide is included in every download, free pack included.

You can also just type the programs in on the calculator's own Python editor if you don't have a cable handy.

TI-84 Evo owners: not this way. TI Connect™ CE doesn't support the Evo. Use connectevo.ti.com in Chrome with a USB-C cable and send the .py files — see the Evo answer above.

What file format do I receive?

A ZIP containing both formats for every program: a .8xv Python AppVar, which is the calculator's own native format and can be dragged straight onto the device, and the matching plain-text .py source.

The .8xv exists so installing is a drag-and-drop rather than a copy-paste. The .py exists so you can actually read the code, check the maths and edit it — which is half the point of buying source rather than a black box.

The .py source is also the portable half of the download: it is what you send to a TI-84 Evo, which uses a different AppVar format and cannot read the .8xv files.

Can I use these on a real exam?

We can't answer that for you, and we don't claim these are approved for any exam — no exam board approves third-party calculator programs in the first place.

What we can tell you is that the rules genuinely differ. The NCEES FE and PE exams don't permit a TI-84 at all. The SAT®, PSAT/NMSQT® and ACT® require stored programs and saved formulas to be removed. AP® Exams follow a different and more permissive published policy, but it concerns the calculator and its memory, not third-party software. Universities and individual instructors set their own rules entirely.

Read your own exam's current policy and ask your instructor or exam administrator. See the section above for the specifics, and treat these as homework, practice and revision tools.

Will Press-to-Test or a memory reset delete these?

Almost certainly yes — back up before you enter exam mode. TI documents that Press-to-Test deletes variables in RAM and archived memory including AppVars, and Python programs on the CE Python are stored as Python AppVars. Unlike Apps and TI-BASIC programs, they are not restored when you leave exam mode. A full memory reset removes them too.

This is easy to work around: copy your .py files back to your computer with TI Connect™ CE first, then re-send them after the exam. Your download stays in your account either way, so you can always re-install — but backing up saves you the trip. Being able to strip the calculator and restore it in two minutes is arguably a feature.

Do I need to know Python?

No. Every program runs from a numbered menu and asks for values in plain English. Knowing Python only helps if you want to modify something — and since you get the source, you can.
