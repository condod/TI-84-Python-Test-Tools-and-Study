Installing takes about five minutes

You need a TI-84 Plus CE Python Edition (or a TI-84 Plus CE with the Python App installed), a USB cable, and TI's free TI Connect™ CE software.

  1. 1

    Download and unzip

    Every bundle ships each program twice: a ready-to-install .8xv Python AppVar and the matching plain-text .py source, plus a README.

  2. 2

    Drag the .8xv files across

    Connect the calculator by USB, open TI Connect™ CE (free from Texas Instruments) and drag the .8xv files onto the device. No copy-pasting code, no retyping.

  3. 3

    Open the Python App and run

    The programs appear in the Python App's list on the calculator. Pick one and run it. That's the whole process.

The .py source is there so you can read the algorithm, change a tolerance or add your own formula — open it in the TI Connect CE Program Editor, or type it straight into the calculator's own Python editor if you don't have a cable to hand. Keep an eye on the roughly 50 KB / 100-program storage limit and archive what you're not using.

Read this before an exam

These are study and practice aids. Calculator and stored-program rules differ sharply between exams, and it is your responsibility to check yours. We make no claim that these programs are permitted on any particular exam — no exam board operates an approval process for third-party calculator software.

  • NCEES FE and PE engineering exams: the TI-84 is not an approved calculator at all, whatever is stored on it. Only certain Casio, HP and TI-30X/TI-36X models are permitted. These programs cannot be used there.
  • SAT®, PSAT/NMSQT® and ACT®: these require you to remove stored programs and clear saved formulas before testing. Remove these programs beforehand.
  • AP® Exams: College Board's published calculator policy is more permissive than most students assume, but it approves calculators, not third-party programs. Read the current policy yourself at collegeboard.org and confirm with your AP coordinator.
  • IB® exams, university midterms and finals: your school, instructor or exam board sets the rules, and many require a memory clear or exam mode. Ask first.

These tools are for homework, practice problems and self-review. They must not be used to gain an unfair advantage on any exam where they are not permitted. Policies change — re-check before every exam, and when in doubt, delete or archive the programs first.

Questions people actually ask

Which calculators does this work on?

The TI-84 Plus CE Python Edition, and a TI-84 Plus CE that has TI's Python App installed. That's it.

It does not work on the older monochrome TI-83 Plus or TI-84 Plus, the TI-84 Plus Silver Edition, the TI-Nspire family, or any Casio or HP calculator. Those either have no Python environment or a different one. If you're unsure, check the label on your calculator's faceplate for "Python" or look for a Python App icon on the home screen before buying.

How do I actually get the programs onto the calculator?

With TI Connect™ CE, Texas Instruments' free desktop software. Connect the calculator over USB, open the Program Editor, create a new Python program, paste in the contents of a .py file and send it to the device. Then run it from the calculator's Python App. A step-by-step guide is included in every download, free pack included.

You can also just type the programs in on the calculator's own Python editor if you don't have a cable handy.

What file format do I receive?

A ZIP containing both formats for every program: a .8xv Python AppVar, which is the calculator's own native format and can be dragged straight onto the device, and the matching plain-text .py source.

The .8xv exists so installing is a drag-and-drop rather than a copy-paste. The .py exists so you can actually read the code, check the maths and edit it — which is half the point of buying source rather than a black box.

Can I use these on a real exam?

We can't answer that for you, and we don't claim these are approved for any exam — no exam board approves third-party calculator programs in the first place.

What we can tell you is that the rules genuinely differ. The NCEES FE and PE exams don't permit a TI-84 at all. The SAT®, PSAT/NMSQT® and ACT® require stored programs and saved formulas to be removed. AP® Exams follow a different and more permissive published policy, but it concerns the calculator and its memory, not third-party software. Universities and individual instructors set their own rules entirely.

Read your own exam's current policy and ask your instructor or exam administrator. See the section above for the specifics, and treat these as homework, practice and revision tools.

Will Press-to-Test or a memory reset delete these?

Almost certainly yes — back up before you enter exam mode. TI documents that Press-to-Test deletes variables in RAM and archived memory including AppVars, and Python programs on the CE Python are stored as Python AppVars. Unlike Apps and TI-BASIC programs, they are not restored when you leave exam mode. A full memory reset removes them too.

This is easy to work around: copy your .py files back to your computer with TI Connect™ CE first, then re-send them after the exam. Your download stays in your account either way, so you can always re-install — but backing up saves you the trip. Being able to strip the calculator and restore it in two minutes is arguably a feature.

Do I need to know Python?

No. Every program runs from a numbered menu and asks for values in plain English. Knowing Python only helps if you want to modify something — and since you get the source, you can.

The whole library is small — these are short text programs, not apps or games. The device holds roughly 50 KB of Python programs and up to 100 programs, and the programs are written with those limits in mind (list inputs are capped, no huge data structures). Most people install only the handful they need for the current course and archive the rest.
